# Ryujinx-Canary-Builds

**Ryujinx-Canary-Builds** is a continuously updated repository of canray builds for testing my [Ryujinx](https://github.com/Ryujinx/Ryujinx) fork, automatically compiled and released after every commit. This fork includes [new performance, better ui, etc].

kindly checkout the [Stabled release](https://github.com/ADEMOLA200/Ryujinx-Stable-Builds/releases) as of the canary release might not be stabled.

## Features

- **Automated Builds:** Every commit triggers an automated build and release process.
- **Canary Releases:** Each build is tested for stability before release.
- **Dynamic Changelog:** A dynamic changelog is generated for each release to track new features and fixes.

## Quick Start

### Download and Run

1. **Download the Latest Release:**
   - Visit the [Releases](https://github.com/ADEMOLA200/Ryujinx-Canary-Builds/releases) page and download the version for your platform.
2. **Installation:**
   - Follow the instructions in the downloaded package for installation.
3. **Run the Application:**
   - Launch the application from your installation directory.
